# ONG Alianza para el Desarrollo — Sitio web oficial

Sitio web institucional de **ONG Alianza para el Desarrollo**, organización guatemalteca sin fines de lucro comprometida con el desarrollo social y comunitario.

🌐 **https://alianzaparaeldesarrollo.ong**

## Acerca del proyecto

Es una página estática de una sola sección (*one-page*) hecha con HTML, CSS y JavaScript, sin frameworks ni backend. Está pensada para cargar rápido, adaptarse a computadora, tablet y teléfono, y ser fácil de mantener.

El sitio se publica con **GitHub Pages** usando el dominio propio `alianzaparaeldesarrollo.ong`.

## Estructura

```
├── index.html        Página principal
├── 404.html          Página de error
├── css/styles.css    Estilos
├── js/main.js        Menú móvil
├── assets/img/       Logo, portada e imágenes
├── favicon.svg/.png  Ícono del sitio
├── robots.txt
├── sitemap.xml
└── CNAME             Dominio personalizado
```

## Editar el contenido

- Los textos están en `index.html`.
- Los colores se cambian en `css/styles.css`, dentro de `:root`.
- Para cambiar una imagen, sube otra con el mismo nombre a `assets/img/`.
- Los textos marcados con `data-provisional` se reemplazarán por el contenido oficial. Si abres el sitio con `?revisar` al final de la dirección, esos textos se resaltan.

Los cambios hechos en la rama `main` se publican solos en uno o dos minutos.
